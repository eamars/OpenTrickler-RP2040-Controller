# v2.0.0

A release candidate, to try the release's files on GitHub before the 2.0 firmware is released. It is a test build: not for use, and not supported. How to install it is not given yet.

What it carries, for the Pico W and the Pico 2 W: a full install for each board, the update images (the Pico W's two, one for each of its slots), an erase for each board, `manifest.json` and `SHA256SUMS`.
