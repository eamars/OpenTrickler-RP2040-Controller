# v2.0.0

**The v2.0 beta.** This is the first release of the 2.0 firmware, for anyone who wants to use it before the formal 2.0 release. It has been tried on the Pico W and the Pico 2 W, with an A&D FX-300i scale. Please report what you find on [Discord](https://discord.gg/ZhdThA2vrW) or in an issue.

The formal 2.0 release comes as an update over Wi-Fi. A unit on this beta offers it on its screen and its web page once it is released, so this is the last time you need the USB cable.

## What is new since v1.21

- **A new menu on the screen.** Everything is reached by turning and clicking the knob, and the reset button or the "<" title takes you back. There is no long press. Whatever a unit needs without the web is on the screen too.
- **A new web page** that works on a phone, a tablet or a computer and needs no internet. It shows the charge with its live weight, the loads, the powders, every setting, and a backup of them.
- **Set-up from a phone.** A new unit starts its own Wi-Fi hotspot and shows a code on its screen. Scan the code, and the page walks you through your Wi-Fi, the scale and the motors.
- **Loads.** A load is a name, a target weight and the powder it is thrown with, and the unit keeps up to eight. Two calibres on one powder are two loads, each with its own weight. The load you choose, with its weight, is still there after a restart.
- **Calibration and auto-tuning.** A calibration (Settings › Calibration) measures the cup, the scale's lag and each powder's flow, and sets the charge's settings from them. With auto-tune switched on, the unit also tunes its control of the fine trickler as it charges.
- **Updates over Wi-Fi.** The unit looks for a new release on GitHub at each start, and whenever you ask (Settings › Firmware › Check for update). It offers what it finds on the main menu and the web page. The stable channel, the default, offers only releases. The beta channel offers betas too.
- **Safer charging.** The tricklers move only on a real, fresh reading from the scale. A reading that cannot be read pauses them, and a scale that is lost or will not settle ends the throw.
- **The motor current you set is the current the driver gives.** The trimmer on the driver module no longer changes it.
- **An API** for programs and agents: a REST API under `/api/v1` that describes itself, and a stream of events. An AI agent given the unit's address can read its guide there and help tune a powder. Writes over the network can require a PIN shown on the unit (Wi-Fi › Options; off by default).
- **A weight is a number alone.** The unit shows what the scale sends and adds no unit. Name your loads and powders with a unit if you like.
- **A fault found at the start is named on the screen.** If a setting cannot be read, or the stored scale is a make the firmware does not know, the main menu's first row says so. With no settings memory or no known scale, the unit does not charge.
- The scale's calibration from the unit is removed: none of the supported scales takes it.

## Before you install, coming from v1.x

- **Make a copy of your settings.** On the v1 web page, go to Settings › System Control › Export Config. The install keeps your settings, so the copy is only in case something goes wrong. The 2.0 web page reads that file under Unit › Backup › Restore from a file.
- **Your settings are kept.** They live on the controller board, not on the Pico, and 2.0 reads what v1.21 stored. That covers your powders, the scale, the Wi-Fi, the motors and the rest. The update was tried from v1.21. From an earlier v1.x, check your settings after the install, and restore your copy if any have gone back to their defaults. A unit on a version before v1.17 starts on the defaults, so restore it from your copy.
- **Set a target before the first charge.** Your chosen powder gets a load named "Load 1" with no target. The unit asks for a target before it charges.
- **The motors keep the current they ran at.** The stored current is converted once, assuming the driver module's trimmer is where the factory set it. If you turned a trimmer, check each motor's current after the update.
- **The unit's name changes once.** Its address becomes `http://opentrickler-XXXX.local`, where `XXXX` is four characters made from the Pico's own id. Its Wi-Fi page shows the name, along with its IP address. The name stays the same from then on, across a factory reset too, so an old bookmark needs updating once. Your router's list of clients also shows each unit by that name, where every unit was `PicoW`.
- **Each unit's hotspot has a password of its own.** The unit's Wi-Fi page shows it while the unit is its own hotspot. The shared password `opentrickler` no longer works.
- **The old web page and its `/rest/` addresses are gone.** A script or an app that used them needs the new API.
- **There is no going back.** An older version installed by USB resets the settings it cannot read.

## How to install

From v1.x, and from any 2.0 release candidate, the install is by USB. Follow [Firmware update via USB](../../manuals/firmware_update_via_usb.md), but take the file from this release's page, not the latest release (which is still v1.21 until 2.0 is released). Your board's file is one of these:

- Raspberry Pi Pico W: `OpenTrickler-2.0.0-pico_w_full_install.uf2`
- Raspberry Pi Pico 2 W: `OpenTrickler-2.0.0-pico2_w_full_install.uf2`

The `update` files are for the update over Wi-Fi: leave them.

A unit on a 2.0 release candidate (2.0.1 to 2.0.3) runs a higher version than this beta, so it is never offered the beta over Wi-Fi. Install the beta on it by USB, as above.

Once the firmware is installed, connect the unit to your Wi-Fi ([OpenTrickler Wireless](../../manuals/connect_to_wireless.md)) and it finds the formal 2.0 release by itself.

## What is not tried yet

- The servo gate has not been tried on a unit with the servos fitted.
- A&D FX-i is the only scale tried on a unit. The other makes are read as v1.21 read them, which was checked on a PC against each make's frames.

## What it carries

For the Pico W and the Pico 2 W:

- a full install for each board;
- the update images, which include the Pico W's two, one for each of its slots;
- `manifest.json` and `SHA256SUMS`.
