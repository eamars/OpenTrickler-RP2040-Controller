# v2.0.3

The fourth release candidate, to try ADR-010's new screen and the update over the air from GitHub before the 2.0 firmware is released. It is a test build: not for use, and not supported. How to install it is not given yet.

Since v2.0.2:
- the screen's menu is new, drawn by LVGL in place of u8g2's MUI (ADR-010): every element reached by the knob, the "<" title or the reset button as Back, no long press; choices on their own page, numbers set in their rows;
- what a unit needs without the web is on the screen too: the scale's frame format and decimals, the fine and coarse stop, the screen's inversion and backlight, the servo gate and its shutters' ends, each motor's direction, the update's channel, Wi-Fi off or on and why it did not join;
- the charge's screen gives the time, the powder and the target again, and a chart of the throw if Charge view is set to Chart; the cleanup is one screen: its weight and flow, its speed set live, the gate, Zero and Stop;
- the unit looks for an update at each start and when asked (Settings › Firmware › Check for update), on the stable channel or the beta, which also offers pre-releases such as this one; an update found is offered on the main menu, and installed from there, over Wi-Fi;
- the charge, a cleanup and an update run in a task of their own, so the screen stays live while they run;
- the scale's calibration is removed: no scale supports it.

What it carries, for the Pico W and the Pico 2 W: a full install for each board, the update images (the Pico W's two, one for each of its slots), `manifest.json` and `SHA256SUMS`.
