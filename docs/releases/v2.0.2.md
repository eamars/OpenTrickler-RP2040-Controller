# v2.0.2

The third release candidate, to try the release's files on GitHub before the 2.0 firmware is released. It is a test build: not for use, and not supported. How to install it is not given yet.

Since v2.0.1:
- each full install writes the whole flash: the firmware, and every other page erased. It leaves the unit in its factory state, with no other firmware kept;
- there is no erase file any more: going back to an older firmware is not offered.

What it carries, for the Pico W and the Pico 2 W: a full install for each board, the update images (the Pico W's two, one for each of its slots), `manifest.json` and `SHA256SUMS`.
